Practice Playlist

Follow this order for a strong HTML/CSS foundation:

  1. Structure: edit headings, paragraphs, and lists.
  2. Layout: move cards using flexbox and grid.
  3. Styling: change colors, fonts, shadows, and spacing.
  4. Responsive: test on mobile and tablet widths.
  5. Polish: add hover effects and smooth transitions.

Challenge Blocks (Do These Yourself)

Challenge 1 — Profile Card

Create a new card with your photo, name, and short bio. Add a button that links to your favorite learning resource.

Challenge 2 — Skills Bar

Make 3 progress bars for HTML, CSS, and JavaScript. Style each bar with different gradient colors.

Challenge 3 — Project Gallery

Build a 3-column gallery section. Add image placeholders and captions for your future projects.
