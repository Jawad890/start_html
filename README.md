# HTML + CSS Coding Lab

This repository now includes a beginner-friendly **hands-on practice project**.

## Files
- `index.html` – structure of the coding lab page
- `styles.css` – styling and responsive layout
- `js..html` – your older practice file (kept for reference)

## How to practice
1. Open `index.html` in your browser.
2. Complete the challenge blocks one by one.
3. Change text, colors, sections, and layout to create your own version.
4. Repeat and build your own mini project playlist.

## Quick run (optional)
```bash
python3 -m http.server 8000
```
Then open `http://localhost:8000`.
